# 🎵 Power – Royal Glassmorphic Music Player

A modern, premium web-based music player built with HTML, CSS, and JavaScript. It features a beautiful glassmorphism UI, dynamic playlists, local music playback, search, and an immersive listening experience.

## ✨ Features

- 🎧 Modern Glassmorphism Design
- 🎵 Play, Pause, Next & Previous Controls
- 📂 Play Local Audio Files
- ☁️ Cloud Upload Interface
- 🔍 Search Songs Instantly
- ❤️ Like Your Favorite Songs
- 📃 Custom Playlists
- 💿 Animated Vinyl Player
- 🎨 Dynamic Theme Colors
- 📱 Fully Responsive Design
- ⚡ Smooth Animations and Transitions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts
