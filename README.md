# 🎵 Power-Player

A modern, responsive web-based music player built with **HTML, CSS, and JavaScript**. Power-Player provides a clean interface and smooth music playback experience directly in your browser.

🌐 **Live Demo:** https://power-player-nu.vercel.app

---

## ✨ Features

* 🎶 Play, pause, next, and previous controls
* 📱 Responsive design for desktop and mobile
* 🎨 Modern and clean user interface
* ⚡ Fast loading and lightweight
* 🌐 Progressive Web App (PWA) support
* 🎵 Smooth audio playback

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

### Clone the repository


### Open the project

Open `index.html` in your browser or use a local development server such as VS Code Live Server.
